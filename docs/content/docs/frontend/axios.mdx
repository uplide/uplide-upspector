`fetch` is captured automatically. axios instances need one line each.

<Tabs items={['Server components', 'Browser']}>
<Tab value="Server components">

```ts title="lib/api.server.ts"
import { attachUpspectorServerAxios } from '@uplide/upspector-next/server';

export const serverApi = axios.create({ baseURL: process.env.API_URL });
attachUpspectorServerAxios(serverApi);
```

</Tab>
<Tab value="Browser">

```ts title="lib/api.ts"
import { attachUpspector } from '@uplide/upspector/axios';

export const browserApi = axios.create({ baseURL: process.env.NEXT_PUBLIC_API_URL });
attachUpspector(browserApi);
```

</Tab>
</Tabs>

<Callout title="Order matters">
  Attach before any interceptor that snapshots response bodies, so the payload
  key is lifted off first.
</Callout>

The interceptor times nothing itself — the backend already measured the
request. It removes the payload key from every response, successes **and**
errors (the backend attaches it to error envelopes too), and hands it to the
overlay. Both functions return a detach function.

## Options

`attachUpspector(api, options)` accepts:

<TypeTable
  type={{
    source: { type: '"csr" | "ssr"', description: 'Where the request ran; shown in the bar.', default: '"csr"' },
    onEntry: {
      type: '(entry: UpspectorEntry) => void',
      description: 'Where entries go.',
      default: 'the browser overlay store',
    },
    inScope: {
      type: '() => boolean',
      description: 'Return false to leave a request untouched (e.g. outside a render).',
    },
  }}
/>
