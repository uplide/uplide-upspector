```bash
pnpm add @uplide/upspector
```

Register a config, install a capture adapter, and render the overlay once.

```tsx title="main.tsx"
import { setUpspectorConfig } from '@uplide/upspector';
import { installFetchCapture } from '@uplide/upspector/fetch';
import { attachUpspector } from '@uplide/upspector/axios';
import { UpspectorOverlay } from '@uplide/upspector/react';

setUpspectorConfig({
  enabled: import.meta.env.DEV,
  match: (url) => url.startsWith(API),
});

installFetchCapture(); // and/or attachUpspector(axiosInstance)

root.render(
  <>
    <App />
    <UpspectorOverlay />
  </>,
);
```

Nothing is captured until a config with `enabled: true` is registered —
capturing is never a fallback. See the [config reference](/docs/reference/config)
for every field.

`installFetchCapture` returns an uninstall function, and is safe to call again
when the host may have swapped `fetch` out: it only re-wraps then.

## Styling

The overlay styles itself. Override the accent color with a CSS variable:

```css
:root {
  --udbg-accent: #7c3aed;
}
```

A developer can also pick their own accent from the gear menu in the panel
header. That choice is stored per browser (`localStorage["upspector.accent"]`)
and wins over the host's value until they press **reset**.

Under a strict Content Security Policy, pass the nonce for the overlay's
`<style>` tag:

```tsx
<UpspectorOverlay nonce={nonce} />
```
