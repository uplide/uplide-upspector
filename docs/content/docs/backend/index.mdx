---
title: NestJS setup
description: Collect an Upspector payload for every request in a NestJS app.
icon: Server
---

```bash
pnpm add @uplide/upspector-nest
```

Peer dependencies: `@nestjs/common` and `@nestjs/core` 10 or newer, `rxjs` 7.

<Steps>
<Step>

### Define the options once

Resolve the options in their own file so the module, the middleware and the
Prisma adapter share one object.

```ts title="src/upspector.ts"
import { resolveUpspectorOptions } from '@uplide/upspector-nest';

export const upspectorOptions = resolveUpspectorOptions({
  enabled: process.env.APP_DEBUG === 'true',
  skip: (req) => (req.originalUrl ?? req.url ?? '').startsWith('/api/health'),
});
```

</Step>
<Step>

### Register the module

`NestUpspectorModule.forRoot` is global. It provides the options under the
`UPSPECTOR_OPTIONS` token and registers `UpspectorInterceptor`, which adds the
route identity and the handler span.

```ts title="src/app.module.ts"
import { NestUpspectorModule } from '@uplide/upspector-nest';
import { upspectorOptions } from './upspector';

@Module({
  imports: [NestUpspectorModule.forRoot(upspectorOptions)],
})
export class AppModule {}
```

</Step>
<Step>

### Wire the middleware

The middleware is not registered through `MiddlewareConsumer` on purpose: add
it with `app.use` **before guards and pipes**, so their queries are captured
too.

```ts title="src/main.ts"
import {
  createUpspectorMiddleware,
  UPSPECTOR_HEADER,
  UpspectorConsoleLogger,
  installAxiosInstrumentation,
  installFetchInstrumentation,
} from '@uplide/upspector-nest';
import axios from 'axios';
import { upspectorOptions } from './upspector';

const app = await NestFactory.create(AppModule, {
  logger: new UpspectorConsoleLogger(),
});

app.enableCors({
  origin: process.env.WEB_ORIGIN,
  exposedHeaders: [UPSPECTOR_HEADER],
});

if (upspectorOptions.enabled) {
  app.use(createUpspectorMiddleware(upspectorOptions));
  installAxiosInstrumentation(axios);
  installFetchInstrumentation();
}
```

</Step>
<Step>

### Instrument your data sources

Wrap the Prisma driver adapter or Drizzle database and Redis clients — see
[Integrations](/docs/backend/integrations).

</Step>
</Steps>

<Callout type="warn" title="CORS">
  Browsers only see `x-upspector` cross-origin when CORS exposes it. Without
  `exposedHeaders: ["x-upspector"]` the browser `fetch` adapter skips the body
  and the bar stays empty for client requests.
</Callout>

## Reading the options elsewhere

The module exposes the resolved options, so code that has no access to your
options file can read them back:

```ts
import { UPSPECTOR_OPTIONS, type ResolvedUpspectorOptions } from '@uplide/upspector-nest';

const options = app.get<ResolvedUpspectorOptions>(UPSPECTOR_OPTIONS);
```

## What gets injected

The payload is added in `res.json`, so it works with any response envelope your
app uses, including error envelopes from exception filters. Only plain-object
bodies carry it; arrays, strings, streams and files are left untouched.
