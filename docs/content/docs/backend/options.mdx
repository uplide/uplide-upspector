```ts
NestUpspectorModule.forRoot({
  enabled: process.env.APP_DEBUG === 'true',
  maxQueries: 500,
  sanitizeParams: (sql, params) => params.map(() => '?'),
});
```

## Limits

When a list hits its limit, further entries are dropped and the section's
`truncated` flag is set; `count` and `totalMs` still cover every entry. Raise a
limit for endpoints that legitimately issue many queries.
